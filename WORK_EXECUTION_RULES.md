# Browser integration constraints

The contract is authoritative for all acceptance results. The client uses the verified complete source and configured Stable Studionet deployment, with explicit wallet signatures and transaction binding. A failed or unknown write must not create a second automatic submission.

The application remains a static browser client without authentication, storage servers or upload services. Public HTTPS images are passed to the contract. Local fixtures are test inputs; production displays actual chain values and the evidence states which flows were measured live.
