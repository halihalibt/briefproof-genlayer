# BriefProof

**BriefProof** is a zero-backend GenLayer application for consensus-based visual deliverable acceptance.

A creator defines a natural-language brief, attaches a public HTTPS image, and specifies 1–6 acceptance criteria. The underlying **Multimodal Acceptance Matrix** Intelligent Contract uses independent Leader / Validator multimodal evaluation and deterministic Material Consequence Equivalence to persist a structured acceptance matrix and final verdict.
